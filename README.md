# Securly Classroom Extension Source Code Archived
This repository contains the extracted source code files of the old Securly Classroom Chrome Web Extension (Version 1.36.1) with the extension ID of: <jfbecfmiegcjddenjhlbhlikcbfmnafd>. This extension is no longer on the Chrome Web Store and has been archived

# Purpose
This has been archived to find vulnerabilites to exploit, find bypasses, see detection system, etc. Also can be used to study JavaScript code but i doubt this specific one would be used for that

# Files

## Core Extension files include

* manifest.json - Extension configuration and permissions
* background.js - Background service worker that handles communication with the server and extension logic
* cs.js - Content script that runs on webpages
